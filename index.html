Berfungsi meneruskan paket data antar subnet berbeda (Inter-VLAN / Inter-Subnet Routing).

Perangkat Layer 2 yang meneruskan frame berdasarkan MAC address (Unicast cerdas).

Hub

Perangkat Layer 1 repeater sederhana yang menyebarkan sinyal ke seluruh port (Broadcast).

Analisis Perangkat

Peran Hub vs Switch vs Router

Hub (Layer 1)

Bekerja di Physical Layer. Setiap data yang masuk ke satu port akan disebarkan (broadcast) ke seluruh port lainnya tanpa peduli siapa tujuan akhirnya. Menyebabkan collision domain yang besar dan kurang efisien.

Switch (Layer 2)

Bekerja di Data Link Layer. Menggunakan tabel MAC Address untuk meneruskan frame secara langsung (unicast) hanya ke port tujuan, sehingga lalu lintas jaringan jauh lebih cepat dan minim kolisi.

Router (Layer 3)

Bekerja di Network Layer. Mampu menghubungkan dua atau lebih subnet/network berbeda dengan memeriksa IP Address tujuan serta menentukan jalur terbaik (routing table) antar jaringan.

Analisis Paket ICMP

Simulation Mode Packet Flow

Saat melakukan tes ping dari PC0 (Subnet A) ke PC2 (Subnet B), Cisco Packet Tracer Simulation Mode mencatat urutan kejadian berikut:

1
ARP Request (Address Resolution Protocol):

PC0 tidak langsung tahu MAC Address Router gateway (192.168.1.1), sehingga PC0 mengirimkan broadcast ARP request ke Switch0.

2
Router Gateway Intercept:

Router menerima ARP request dan membalas dengan ARP Reply menyertakan MAC Address interface Fa0/0 miliknya.

3
ICMP Echo Request (Ping Packet):

Paket ICMP dikirim dari PC0 menuju Router, diteruskan melalui antarmuka Router ke Subnet B, hingga tiba di PC2.

4
Echo Reply & Success:

PC2 mengirimkan balik paket ICMP Echo Reply ke PC0. Status paket berubah menjadi Successful.

Selesai & Terverifikasi

Kesimpulan Praktikum Jaringan Komputer

  • Pengalamatan IP (IP Address & Subnet Mask) yang benar serta pengaturan Default Gateway sangat krusial agar host pada subnet berbeda dapat saling berkomunikasi.
  • Router berperan mutlak sebagai perangkat Layer 3 untuk menghubungkan segmen jaringan yang terisolasi, sementara Switch dan Hub menangani komunikasi di dalam LAN lokal.
